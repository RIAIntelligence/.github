## RIAIntelligence

We help independent RIAs adopt AI on the Microsoft 365 they already pay for.

### The repositories

| | |
|---|---|
| **[hq](https://github.com/RIAIntelligence/hq)** | Think tank and company hub. Decisions, research, how we work. Start at `plan/context.md`. |
| **[prototype](https://github.com/RIAIntelligence/prototype)** | The 2026 prototype, serving the live domains until the rebuild replaces it. No new work here. |

`product`, the rebuild, is created when the first code exists.

### Where to start

- **New here** → `hq/plan/context.md`
- **Looking for why something was decided** → `hq/plan/decisions.md`
- **Looking for a fact about the market, a vendor, or a regulation** → `hq/research/`
- **Looking for work assigned to you** → issues in `company`, labeled with your name
