# RIAIntelligence

**Raya** is an assistant for the staff of independent advisory firms: a chat with the firm's work open beside it.
Every figure it shows comes from the firm's own data, and nothing leaves the firm without a person's approval.

We are a small team that builds with Claude Code agents. Every change lands by pull request, passes its checks and an
independent review, and is released from `main`.

Our repositories are private.
