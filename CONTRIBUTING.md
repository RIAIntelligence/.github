# Contributing

1. Work on a branch and open a pull request against `main`. One change per pull request.
2. Reference its issue with `Refs #n`. An issue closes when the fix is live, not at merge.
3. Required checks must pass, and an independent review of the diff is posted on the pull request before it merges.
4. Never commit a secret. Push protection blocks known patterns; keys live in the team's vault.
